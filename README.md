# JayZ Care 🩺

**Accessible healthcare information. Smarter navigation. Better-connected communities.**

JayZ Care is an early-stage healthcare technology prototype exploring how digital tools can help people access health education, navigate healthcare services, discover providers, and find appropriate general guidance.

The project is being developed with a community-focused vision for Plateau State, Nigeria, with potential to expand to other communities.

## Features

- **Health Education:** General health tips and educational resources.
- **Find a Facility:** Explore sample healthcare facility listings.
- **Book an Appointment:** Demonstration appointment-request interface.
- **Emergency Help:** General safety guidance and emergency-support information.
- **Provider Directory:** Browse example healthcare provider listings.
- **Guided Assistant:** A basic, rule-based assistant for general health navigation.
- **About & Safety:** Information about the project's purpose and limitations.

## Technology

- Python
- Streamlit
- GitHub
- Streamlit Community Cloud

## Project status

**Version:** 0.2 — early-stage MVP prototype.

This project is currently a demonstration. Unless explicitly verified in the running app, listings and contact details may be sample data or placeholders. It is not connected to live appointment systems, emergency dispatch, or a verified provider network. The guided assistant is not a diagnostic tool.

## Run locally

1. Install Python.
2. Clone the repository (replace `YOUR-GITHUB-USERNAME` with your GitHub username):

   ```bash
   git clone https://github.com/YOUR-GITHUB-USERNAME/jayz-care.git
   cd jayz-care
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the app:

   ```bash
   streamlit run app.py
   ```

## Privacy and safety

Do not submit real patient records, sensitive personal information, or confidential medical details to this prototype. Its educational content does not replace advice from a qualified healthcare professional, and it is not an emergency-response service. In an emergency, contact verified local emergency services or go to the nearest appropriate healthcare facility.
